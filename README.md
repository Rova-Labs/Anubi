# 𓂀 أنوبي: مهد الحضارة (Anubi: Cradle of Civilization)

مرحباً بك في "أنوبي"، البوابة الرقمية الاستثنائية لاستكشاف عمق التاريخ المصري عبر الزمن. هذا المشروع ليس مجرد موقع إلكتروني، بل هو رحلة معرفية تفاعلية تأخذك إلى قلب الحضارة المصرية القديمة والمواقع التراثية المصرية الخالدة.

## 🏺 مميزات المشروع
* **بوابة دخول ملكية:** نظام تسجيل دخول يمنح المستخدم ألقاباً فرعونية وملكية تتطور مع تقدمه في الاستكشاف.
* **قصص تفاعلية:** استكشف أسرار وادي الملوك، هيراكليون، وغيرها من المواقع الأثرية عبر واجهة عصرية.
* **الرفيق الرقمي (أنوبي):** مرافقك الذكي الذي يرشدك ويشاركك المعلومات بلمسة تفاعلية.
* **هوية بصرية فاخرة:** تصميم مستوحى من نقوش وعظمة الحضارة المصرية القديمة مع دمج التقنيات الحديثة.

## 🛠 التقنيات المستخدمة
* **HTML5:** لهيكلة المحتوى بشكل دلالي وواضح.
* **CSS3:** لتصميم واجهات فاخرة (Gold theme) ورسوم متحركة فريدة.
* **JavaScript:** لإدارة الجلسات النشطة، المنطق البرمجي، والتفاعل الصوتي مع المستخدم.

## 🚀 رحلة الاستكشاف
1. ابدأ رحلتك من **بوابة الدخول**.
2. اختر قصتك المفضلة من خريطة الاستكشاف.
3. تفاعل مع "أنوبي" واجمع النقاط لترتقي برتبتك من "مستكشف مبتدئ" إلى "فرعون/ملكة أسطورية".
